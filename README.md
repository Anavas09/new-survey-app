# New Survey App

Aplicación web para la creación, gestión y análisis de encuestas, desarrollada con React y Express. Permite a los usuarios crear encuestas personalizadas, recolectar respuestas y visualizar resultados en tiempo real.

## Características principales
- **Creación de encuestas**: Interfaz intuitiva para diseñar encuestas con diferentes tipos de preguntas.
- **Gestión de respuestas**: Almacenamiento seguro y visualización de resultados.
- **Internacionalización (i18n)**: Soporte multilenguaje usando i18next.
- **Panel de administración**: Gestión de encuestas, usuarios y resultados.
- **Notificaciones y validaciones**: Experiencia de usuario mejorada con Material UI y validaciones en tiempo real.
- **Backend Express**: API REST para operaciones CRUD y manejo de archivos con Multer.

## Tecnologías principales
- React 18
- Material UI
- Zustand (gestión de estado)
- i18next y react-i18next
- Express.js
- Multer
- TypeScript
- Yarn 4

## Scripts disponibles
- `yarn dev`: Compila y ejecuta el backend y frontend.
- `yarn start`: Inicia el servidor Express.
- `yarn build`: Compila la app para producción.
- `yarn test`: Ejecuta los tests.

## Instalación rápida
```bash
yarn install
yarn dev
```

La app estará disponible en [http://localhost:3000](http://localhost:3000).
